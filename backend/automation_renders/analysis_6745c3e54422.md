$\frac{\omega_0}{3}$

【解析】
由于飞轮系统绕光滑固定轴转动，在啮合过程中，系统所受外力矩为零，故系统对转轴的角动量守恒。

啮合前，仅飞轮 $A$ 转动，系统的初始角动量为 $L_0 = J_1 \omega_0$。

啮合后，飞轮 $A$ 与飞轮 $B$ 以共同角速度 $\omega$ 转动。已知飞轮 $B$ 的转动惯量为 $J_B = 2J_1$，则系统总转动惯量为 $J_{\text{总}} = J_1 + J_B = 3J_1$，此时系统的末角动量为 $L = J_{\text{总}} \omega = 3J_1 \omega$。

根据角动量守恒定律 $L_0 = L$，有 $J_1 \omega_0 = 3J_1 \omega$。

联立方程解得系统的共同角速度为 $\omega = \frac{\omega_0}{3}$。
