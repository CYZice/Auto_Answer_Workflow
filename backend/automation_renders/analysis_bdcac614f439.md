【正解】$\frac{\omega_0}{3}$

【解析】
由题意可知，飞轮 $A$ 的转动惯量为 $J_1$，飞轮 $B$ 的转动惯量为 $J_2 = 2J_1$。由于系统绕光滑固定轴转动，在两飞轮啮合过程中，系统所受外力矩之和为零，故系统满足角动量守恒定律。

啮合前，系统总角动量为 $L_{\text{初}} = J_1 \omega_0$。啮合后，两飞轮绕同一转轴以共同角速度 $\omega$ 转动，此时系统总转动惯量为 $J_{\text{总}} = J_1 + J_2 = 3J_1$，则系统总角动量为 $L_{\text{末}} = (3J_1) \omega$。

根据角动量守恒定律 $L_{\text{初}} = L_{\text{末}}$，可得方程 $J_1 \omega_0 = 3J_1 \omega$。联立化简得，啮合后整个系统的角速度为 $\omega = \frac{\omega_0}{3}$。
