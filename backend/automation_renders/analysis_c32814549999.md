$\omega = \frac{1}{3}\omega_0$

【解析】
设飞轮 $A$ 的转动惯量为 $J_1$，初角速度为 $\omega_0$；飞轮 $B$ 的转动惯量为 $J_B = 2J_1$，初角速度为 $0$。

由于两飞轮在绕同一转轴转动的过程中，系统所受合外力矩为零，根据角动量守恒定律，系统在啮合前后的总角动量保持不变，即 $L_{\text{始}} = L_{\text{末}}$。

根据角动量定义 $L = J\omega$，可列出方程：
$J_1\omega_0 + J_B \cdot 0 = (J_1 + J_B)\omega$

代入 $J_B = 2J_1$ 得：
$J_1\omega_0 = (J_1 + 2J_1)\omega$
$J_1\omega_0 = 3J_1\omega$

解得啮合后整个系统的角速度为：
$\omega = \frac{1}{3}\omega_0$
